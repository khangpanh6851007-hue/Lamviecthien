# Trạm Phước Đức --- Ultra 2026

Ứng dụng web tĩnh mang phong cách tâm linh hiện đại, giao diện tối xanh
navy và vàng kim. Thiết kế responsive, có thể chạy trực tiếp trên trình
duyệt mà không cần cài đặt máy chủ.

## ✨ Tính năng

-   **Giao diện Ultra 2026:** bố cục hiện đại, tương thích điện thoại,
    máy tính bảng và desktop.
-   **Chế độ sáng / tối:** chuyển đổi giao diện theo sở thích.
-   **Đồng hồ & ngày tháng:** hiển thị thời gian trên thiết bị và đồng
    hồ mô phỏng Cung Trời Hóa Lạc.
-   **Đếm ngược:** theo dõi mốc thời gian đến ngày 31/12/2124.
-   **Bộ đếm phước đức:** ghi nhận số lần tích phước, mục tiêu mỗi ngày
    và chuỗi ngày duy trì.
-   **Cấp bậc thành tựu:** các mốc danh hiệu dựa trên số lần tích phước.
-   **Lời nhắc tích cực:** hiển thị câu nói ngẫu nhiên.
-   **Tìm kiếm liên kết:** lọc nhanh các liên kết tiện ích có sẵn trong
    ứng dụng.
-   **Lưu dữ liệu trên thiết bị:** dữ liệu được lưu bằng `localStorage`
    của trình duyệt.

## 🚀 Chạy ứng dụng

### Cách 1: Mở trực tiếp

1.  Tải hoặc clone repository.
2.  Mở file `index.html` bằng trình duyệt hiện đại.

### Cách 2: Chạy bằng GitHub Pages

1.  Đưa file `index.html` lên repository GitHub.
2.  Mở **Settings → Pages**.
3.  Trong **Build and deployment**, chọn **Deploy from a branch**.
4.  Chọn nhánh `main` và thư mục `/(root)`, sau đó nhấn **Save**.
5.  Chờ GitHub Pages triển khai và mở URL được cung cấp trong phần
    Pages.

## 💾 Dữ liệu & quyền riêng tư

-   Dữ liệu bộ đếm và thiết lập được lưu cục bộ trong trình duyệt thông
    qua `localStorage`.
-   Xóa dữ liệu trang web hoặc đổi trình duyệt/thiết bị có thể làm mất
    dữ liệu đã lưu.
-   Phiên bản này không cung cấp đồng bộ dữ liệu lên máy chủ hoặc giữa
    nhiều thiết bị.
