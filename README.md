# Làm Việc Từ Thiện Tăng Phước Báo - Giao Diện 5.0 Ultra

Dự án giao diện web hiện đại được thiết kế theo phong cách **Glassmorphism Ultra** kết hợp chủ đề đạo đức, từ thiện và tâm linh, tối ưu hóa hiển thị trên cả máy tính và thiết bị di động.

---

## 🌟 Tính Năng Nổi Bật

* **Hiệu ứng Glassmorphism & Neon:** Giao diện kính mờ sang trọng với các điểm nhấn ánh sáng vàng/cam ấm áp.
* **Khung Thâm Nghĩa Đạo Đức:** Hiển thị bài thơ tâm linh tạo cảm giác thanh tịnh ngay từ cái nhìn đầu tiên.
* **Hệ Thống Liên Kết Đa Dạng:** Tích hợp danh sách các trang web liên kết quan trọng với hiệu ứng tương tác mượt mà (`hover`, `pulse`, `glow`).
* **Hoàn Toàn Thích Ứng (Responsive):** Tương thích hoàn hảo với mọi kích thước màn hình từ điện thoại thông minh đến máy tính bảng và PC.
