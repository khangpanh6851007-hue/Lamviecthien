# 🌟 Trạm Phước Đức - Tâm Linh Modern

> Hệ thống hỗ trợ tu tâm tích phước hằng ngày, thiết kế theo phong cách giao diện hiện đại (Modern Web App) dành riêng cho **KhangPanh68**.

---

## 📱 Giới thiệu dự án

**Trạm Phước Đức** là một trạm không gian trực tuyến tích hợp các công cụ hỗ trợ tu dưỡng tâm hồn, gieo duyên lành, theo dõi lịch âm dương và truy cập nhanh vào hệ sinh thái các trang web tâm linh bổ ích. 

Ứng dụng được tối ưu hóa hoàn hảo cho cả thiết bị di động (Mobile) lẫn máy tính với trải nghiệm mượt mà, giao diện tối (Dark Mode) thân thiện với mắt và tính năng lưu trữ dữ liệu cá nhân cục bộ (`localStorage`).

---

## ✨ Các tính năng nổi bật

- 📅 **Widget Lịch & Ngày Chay:** Tự động cập nhật ngày tháng năm hiện tại, đồng thời nhận diện trạng thái ngày chay / ngày thường trực quan.
- 🙏 **Gieo Duyên Lành (Tích Phước):** Nút tương tác bấm niệm lành, tự động ghi nhớ và cộng dồn tổng số câu niệm tích lũy của bạn qua từng ngày.
- 📜 **Góc Lời Khuyên Tâm Linh:** Cung cấp các câu nói, châm ngôn hướng thiện, giúp tâm hồn thanh thản và có thể đổi mới câu nói bất cứ lúc nào.
- 🔗 **Hệ Thống Liên Kết Nhanh:** Truy cập nhanh chóng đến toàn bộ các trạm thành viên trong hệ sinh thái tâm linh (Sấm Trạng Trình, Cung Trời Hóa Lạc, Tây Phương Cực Lạc, Bảng Phong Thần, Giải Phong Ấn...).

## 🛠️ Công nghệ sử dụng

- **HTML5 / CSS3:** Xây dựng cấu trúc trang và giao diện tùy chỉnh với Flexbox, CSS Variables.
- **JavaScript (ES6):** Xử lý logic tương tác người dùng, quản lý bộ nhớ `localStorage`, cập nhật ngày tháng và thay đổi lời khuyên ngẫu nhiên.
- **FontAwesome (v6.4.0):** Hệ thống biểu tượng trực quan, sinh động.
- **Google Fonts:** Phông chữ `Inter` (hiện đại, sắc nét) kết hợp `Lora` (mang phong cách cổ điển, trang nghiêm cho lời khuyên).

## 🚀 Hướng dẫn sử dụng / Triển khai

1. Tải hoặc sao chép mã nguồn file `index.html`.
2. Đưa lên kho lưu trữ **GitHub Repository** của bạn (hoặc kích hoạt **GitHub Pages** để xuất bản thành web app online).
3. Truy cập đường dẫn trang web trên trình duyệt điện thoại hoặc máy tính để bắt đầu hành trình tích phước hằng ngày!
